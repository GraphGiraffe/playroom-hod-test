# ХОД — зашифрованный сайт

[Сайт](https://graphgiraffe.github.io/playroom-hod-test/) публикует приложение ХОД как защищённую паролем PWA с каталогом игр. Этот репозиторий — зеркало поставки; исходники приложения и коллекции находятся в отдельных репозиториях.

## Устройство

- `source/app.enc` — зашифрованный входной пакет; ключи не хранятся в Git.
- `source/salt.txt` — стабильная несекретная соль для запомненного доступа.
- После входа браузер хранит одну проверенную расшифрованную копию оболочки для работы офлайн.
- Сохранения и настройки принадлежат этому origin и не переносятся с других сайтов автоматически.

Пароль ограничивает первоначальный доступ, но не запрещает пользователю сохранить уже расшифрованное приложение. Открытый репозиторий и публичный сайт не должны содержать пароли, ключи, browser storage или расшифрованные входные файлы.

## Подготовка и публикация

Скрипты подготовки зашифрованного сайта находятся в `scripts/`; их происхождение и SHA256 записаны в `scripts/tool-provenance.json`. Приложение публикуется как отдельная оболочка, а игры устанавливаются из каталога — без GitHub Releases приложения или коллекции.

Публикация запускается вручную через **Actions → Publish encrypted PlayRoom** на `main`. Push и PR не публикуют сайт. Workflow собирает и публикует зашифрованные файлы; браузерную приёмку выполняйте локально.

Секреты GitHub Actions: `PAGES_SMOKE_PASSWORD` — пароль сайта; `SOURCE_BUNDLE_KEY` — ключ входного пакета. Их значения нельзя добавлять в Git, логи или отчёты. Переподготовка входного пакета меняет транспортный ключ и не должна выполняться одновременно с публикацией.

Каталог содержит текущие игры. В файлах поставки сохранены стабильные паки начиная с поставки приложения 0.20; прежние паки и prerelease/preview удалены по принятой политике очистки. Изменения готовятся через PR в `dev`, затем объединяются в `main`. Обе ветки синхронизируются; публикация остаётся ручной из `main`.

## Превью Калякодила

Отдельная страница: `/playroom-hod-test/api/packs/preview/kalyakodil/`.
В ней только три review-варианта A/B/C 0.1.2; они не входят в dev коллекции
до проверки владельцем и выбора одного основного варианта.
Пароль тот же: workflow использует существующий `PAGES_SMOKE_PASSWORD`.
Транспортный ключ `PREVIEW_KALYAKODIL_SOURCE_KEY` отдельный; основной
`SOURCE_BUNDLE_KEY` и соль входа основного сайта не меняются.

Ручной **Publish Kalyakodil preview only** берёт 63 файла текущей основной
публикации по SHA256 из baseline, добавляет только подкаталог превью и
отклоняет любые изменения вне него. Если основная поставка обновилась,
baseline требуется явно обновить; workflow не откатывает её автоматически.
Обычный **Publish encrypted PlayRoom** при следующем разрешённом выпуске
также включает отдельное превью. Оба workflow используют одну concurrency group.

Путь внутри `api/packs/` выбран потому, что установленный основной worker
уже пропускает его. Изменять основной worker не требуется. У превью
собственные PWA ID, namespace local/session storage, IndexedDB, оконных
кэшей и Web Locks; основной профиль и сохранения не импортируются.
Исходники входной оболочки зашифрованы, файлы review-паков публичны.
